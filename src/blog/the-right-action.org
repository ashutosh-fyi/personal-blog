I've been obsessed with this question forever, trying to find an answer.
Perhaps, I was looking at the wrong place, I say this because I've been reading the Bhagavad Gita, which answers this question precisely.
It says, the right action is the one that kills the ego. I knew this before, but we can only appreciate it when we observe our ego, the actions which need to be taken appear then.
I don't yet know if this is the right interpretation, but it's the one I've going with for now
